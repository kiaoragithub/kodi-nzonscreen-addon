# NZ On Screen for Kodi

Unofficial Kodi video add-on for the public catalogue at nzonscreen.com.

## Features

- Home, television, film, series, music video, collection, interview, profile and NZOS+ pages
- First-level and deeper nested website pages
- Search and browse by live site categories, genres and decades
- Multiple clips per page, metadata, artwork and subtitles
- Short-lived token retrieval at playback time
- Encrypted MPEG-DASH/Widevine playback through Kodi InputStream Adaptive
- Kodi 21 Omega / Python 3 compatible

## Install

In Kodi choose **Settings → Add-ons → Install from zip file**, select the supplied ZIP,
then open **Add-ons → Video add-ons → NZ On Screen**. Kodi may ask to install or enable
InputStream Adaptive and the Widevine CDM the first time a protected video is played.

Availability, rental access and geographic restrictions are enforced by NZ On Screen.
This add-on does not bypass login, payment or DRM.
